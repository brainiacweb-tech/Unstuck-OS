# User guide

Complete onboarding, then describe a task in the search box. Arrow keys select a result and Enter opens its guidance. Ctrl+K focuses search. Star useful tasks for the Dashboard. Settings tasks require you to approve navigation; they do not change settings.

Troubleshooting offers internet, microphone and camera checks. Approve only the media you intend to test. Review evidence, open the relevant privacy or connection settings, make an informed change, and repeat the same test. Previous results remain visible for comparison. A passing endpoint test does not guarantee all internet services work.

Performance shows a refreshable snapshot. Activation provides legitimate account/license guidance; it does not inspect or change activation status. Folder creation asks you to choose a parent and confirm a new empty Unstuck Folder. A collision is reported rather than overwritten.

Preferences controls theme, optional global shortcut, history and data reset. Clear history removes saved network tests and recent tasks. Review locally stored data displays exactly the current settings and records.

## Built-in help and onboarding

Open **Help & Support** for offline help search, tutorials, FAQs and local problem reporting. Preferences includes **Restart onboarding**, **Restart guided tour**, help-tip and beginner-explanation switches, and links to the About page. The native **Help** menu also opens About and Report a Problem. About identifies Francis Kusi as creator/developer and reads the version from package metadata. Reports require an explicit preview before copying or saving; nothing is sent automatically. See [HELP-ONBOARDING.md](HELP-ONBOARDING.md).

## Issue assistant

Choose **Issue assistant** or **Describe an issue** on the Dashboard. Describe storage, network or another computer problem. Supported read-only checks run automatically. Storage candidates require exact file selection and native approval before permanent deletion. DNS repair runs its fixed command and retests after approval. Unrecognized issues can use **Find online guidance**, which previews your issue text before opening Microsoft Support. No diagnostic data is attached. See [ISSUE-ASSISTANT.md](ISSUE-ASSISTANT.md) for the actual automation scope and limits.

Light mode now uses softer blue-gray surfaces instead of white panels. Use the theme button to switch; your choice remains saved.
