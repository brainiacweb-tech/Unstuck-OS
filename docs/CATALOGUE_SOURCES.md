# Catalogue references

Primary references checked 2026-11-06. These references support the catalogue/guidance; they do not replace manual destination and hardware acceptance.

- Windows Settings URI reference: https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings
- Windows keyboard shortcuts: https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows
- Accessibility shortcuts: https://support.microsoft.com/en-us/accessibility/windows/windows-keyboard-shortcuts-for-accessibility
- Browser shortcuts (Edge; behavior varies in other applications): https://support.microsoft.com/en-us/edge/keyboard-shortcuts-in-microsoft-edge
- PowerPoint presentation shortcuts: https://support.microsoft.com/en-us/accessibility/powerpoint/use-keyboard-shortcuts-to-deliver-powerpoint-presentations
- Windows activation: https://support.microsoft.com/en-us/windows/activation/activate-windows
- Activation errors: https://support.microsoft.com/en-us/windows/activation/get-help-with-windows-activation-errors
- Office activation: https://support.microsoft.com/en-us/microsoft-365-activation-licensing/office-install/unlicensed-product-and-activation-errors-in-office
- Electron async clipboard API: https://www.electronjs.org/docs/latest/api/clipboard

Shortcuts are never executed automatically. Copy only writes a selected known chord, and the main process verifies it. Windows build/application dependencies are explained in the library and relevant guidance.
